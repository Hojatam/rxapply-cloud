Why V2 before going online

Phase A→E proved the architecture. The local stack runs, 21 agents ship, smoke harness is green. What's missing is the operator surface: a single dashboard that lets you toggle services, drive any agent, ask follow-up questions, see full I/O, train prompts, and chain agents — without dropping into a terminal. That's what V2 builds. Going live without it means flying blind once n8n is hitting real platforms.

Today
Two dashboards, fragmented

read-only test scorecard + ops dashboard. No service control. No agent chat. Logs are headlines only.

After F
One control plane

single dashboard with 9 sections, full I/O logs, chat with any agent, visual pipeline editor, design pipeline via Afshin.

After G/H/I
Real data → live

Phase F unlocks G (real signals), H (auth + send-auth gates), I (Telegram → Stripe → first $79).

10 deliverables

Each is a self-contained chunk. The dashboard skeleton (F1) lands first; everything else fills in sections of it.

▶ F1 Workspace move + dashboard skeleton ~2h

Single-page dashboard.html with sidebar + topbar layout. 9 sections wired empty (Overview · Services · Workflows · Agents · Pipelines · Logs · Approvals · Designs · Settings 🔒). Old dashboards moved to legacy/.

move-to-c-dev.bat handles workspace move: pre-flight checks · stop services · pg_dump · robocopy · update paths · restart · post-flight checks.

▶ F2 Logs L2 — full I/O capture ~3h

Migration 20260501000000_logs_l2.sql: adds input_payload, output_payload, error_payload, log_file_path, cost_usd_actual to agent_runs; creates agent_actions table.

Helper module cowork-proxy/log-writer.js: every /run-helper invocation auto-writes logs/YYYY-MM-DD/<agent>-<runid>.{json,stdout,stderr}. 30-day retention, gzip after 7 days.

Routes: GET /logs?filter=… · GET /logs/:runid · GET /logs/:runid/download.

Dashboard "Logs" section: searchable table, expand row → tabs (Input · Actions · Output · Errors), download zip button.

▶ F7 Settings + prompt versioning (built early) ~3h

Migration: prompt_versions(agent, version, body, edited_at, edited_by, diff) + agent_chats.

Auth middleware on /settings/* + /prompts/*: bcrypt hash in env, session cookie, 4h expiry.

Settings panel: prompt editor with version history · side-by-side diff · rollback · sandbox toggle · API keys (masked) · monthly cap input.

Built before F5/F8 because both need API keys + the auth gate.

▶ F3 Service control panel ~2h

Routes: GET /services · POST /services/:name/{start,stop,restart}. docker stop/start for Supabase/n8n/MailHog. Cowork-proxy uses proxy-watchdog.bat as parent watcher (it can't stop itself mid-request, so the watchdog handles it).

Dashboard: 4 cards — toggle, status (green/red/amber), uptime, last action log.

Confirms before stopping anything that has in-flight requests.

▶ F4 Workflow control via n8n REST API ~2h

Routes: GET /n8n/workflows · PATCH /n8n/workflows/:id/active · POST /n8n/workflows/:id/run · POST /n8n/workflows/import. Library = the 5 JSONs in n8n-workflows/.

Dashboard: list with toggle / run-now / import-from-library buttons + last-execution status pill.

▶ F5 Agent run + chat (Anthropic streaming) ~4h

22-agent grid in "Agents" section grouped by division (Content · Engagement · Intel · Ops · Inspection · Design). Click → tabbed pane:

  • Skill — read SKILL.md (RO from this tab; edit lives in protected Settings)
  • Run — form-driven helper invocation (existing /run-helper)
  • Chat — streaming Claude conversation. Sends SKILL.md + last 10 agent_runs + your question as system+context. SSE.
  • History — last 50 invocations + chats
  • Forward — hand result to next agent (linear hand-off pairs)

New routes: POST /agent/:name/chat (SSE) · GET /agent/:name/chats · POST /agent/:name/forward. Persisted to agent_chats.

▶ F9 Cost telemetry + monthly cap ~2h

Proxy intercepts every paid API call (Anthropic + OpenAI), records token counts and dollar cost into agent_runs.cost_usd_actual.

Top-strip widget: today / 7d / 30d running totals. Hard cap (default $25/mo, configurable in Settings): warns at 80%, blocks at 100%. Reset on first of month.

▶ F8 Afshin — design agent ~5h

New agent agents/afshin/{SKILL.md, afshin.py, drafts/, renders/}. Migration: media_library table.

5 deliverable kinds: ig_carousel_slide · telegram_cover · youtube_thumb · web_banner · email_header_ravi.

Two routes:

  • Draft (POST /afshin/draft) — Claude generates SVG/HTML mock. ~$0.005/draft. Shipped now.
  • Render (POST /afshin/render/:draft_id) — gpt-image-1 produces final raster. ~$0.05/render. Greyed-out until OPENAI_API_KEY set.

Dashboard "Designs" section: gallery + draft preview + "Approve & Render" button + "Used by" chip showing which agents pulled the asset via media_library.

Other agents pull via SELECT * FROM media_library WHERE kind=$1 AND approved=true ORDER BY created_at DESC LIMIT 1.

▶ F6 Visual pipeline editor (Drawflow) ~7h

Drawflow.js (vanilla, ~10KB MIT, CDN-loaded). Full canvas in "Pipelines" section. Node types:

  • Agent — 22 instances, ports based on helper signature
  • Conditional — if-then-else on output value (stretch)
  • Transform — small JS expression, e.g. $prev.brief_id
  • Output — write to journal / file / forward to webhook

Save/load: pipelines/<name>.json. Run pipeline = topological execution with streaming results, full run logged with pipeline_id.

▶ F10 smoke-v2.bat ~2h

End-to-end PASS/FAIL across:

  • 4 services controllable from proxy
  • Log L2 roundtrip — agent run → log file → API → downloadable zip
  • Prompt edit → version saved → rollback works
  • Anthropic chat returns stream
  • Afshin draft generates valid SVG
  • (if OPENAI key) Afshin render generates valid PNG
  • Cost cap blocks call when exceeded (test mode forces over-cap)
  • Pipeline runs 3-node chain end-to-end

Schema additions

Three new migrations on top of the 17-table baseline.

F2 20260501000000_logs_l2.sql 
ALTER TABLE agent_runs
  ADD COLUMN input_payload   jsonb,
  ADD COLUMN output_payload  jsonb,
  ADD COLUMN error_payload   jsonb,
  ADD COLUMN log_file_path   text,
  ADD COLUMN cost_usd_actual numeric(10,4) DEFAULT 0;

CREATE TABLE agent_actions (
  id           uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  run_id       uuid REFERENCES agent_runs(id) ON DELETE CASCADE,
  step_index   int NOT NULL,
  action_kind  text NOT NULL,   -- 'sql' | 'http' | 'file_write' | 'subprocess' | 'llm_call'
  action_data  jsonb,           -- {sql:"…"} or {url:"…", method:"POST", status:200} etc.
  duration_ms  int,
  created_at   timestamptz DEFAULT now()
);
CREATE INDEX idx_agent_actions_run ON agent_actions(run_id, step_index);
F7 20260502000000_prompts_chats.sql 
CREATE TABLE prompt_versions (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  agent       text NOT NULL,
  version     int NOT NULL,
  body        text NOT NULL,
  edited_by   text DEFAULT 'founder',
  edited_at   timestamptz DEFAULT now(),
  diff_chars  int,
  UNIQUE (agent, version)
);
CREATE INDEX idx_prompt_versions_agent ON prompt_versions(agent, version DESC);

CREATE TABLE agent_chats (
  id            uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  agent         text NOT NULL,
  started_at    timestamptz DEFAULT now(),
  last_msg_at   timestamptz DEFAULT now(),
  messages      jsonb DEFAULT '[]'::jsonb,
  run_context   uuid REFERENCES agent_runs(id),
  total_tokens  int DEFAULT 0,
  total_cost    numeric(10,4) DEFAULT 0
);
CREATE INDEX idx_agent_chats_agent ON agent_chats(agent, last_msg_at DESC);
F8 20260503000000_media_library.sql 
CREATE TABLE media_library (
  id              uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  kind            text NOT NULL,    -- 'ig_carousel_slide' | 'telegram_cover' | …
  prompt          text NOT NULL,
  draft_path      text,             -- assets/generated/drafts/.svg
  render_path     text,             -- assets/generated/renders/.png
  dimensions      text,             -- "1080x1080"
  owner_agent     text DEFAULT 'afshin',
  approved        boolean DEFAULT false,
  used_by         text[] DEFAULT '{}',
  metadata        jsonb DEFAULT '{}',
  created_at      timestamptz DEFAULT now()
);
CREATE INDEX idx_media_library_kind ON media_library(kind, approved, created_at DESC);

Risks

Anthropic SSE breaks through Express → fetch → browser

Mitigation: F5 starts with a 30-min spike to verify SSE survives the proxy. Fallback = polling-based pseudo-stream.

Drawflow conditional support is thin

Mitigation: F6 starts linear-only; conditional node is stretch and may slip to G.

Workspace move breaks docker volumes

Mitigation: move-to-c-dev.bat does pre-flight pg_dump, stops services in order, robocopy /MIR, restart, post-flight smoke check.

22-node grid feels cluttered

Mitigation: F1 dashboard groups agents by division (collapsible), default-collapsed except active.

Afshin draft-only ships, render added later → UI inconsistency

Mitigation: F8 builds "Approve & Render" button greyed-out with tooltip "OPENAI_API_KEY missing." Drop key, button activates.

logs/ folder grows unbounded

Mitigation: F2 includes 30-day retention, gzip after 7 days. Cleanup runs on proxy startup.
